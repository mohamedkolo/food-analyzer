# إثبات ملكية الموقع لجوجل

## ليه التحقق فشل

لو اخترت **«موفّر اسم النطاق» (Domain property)**، جوجل بيطلب منك تضيف سجل
TXT في الـ DNS بتاع النطاق. وده **مستحيل** مع اللينك الحالي:

```
food-analyzer-duag.onrender.com
```

ده نطاق فرعي من `onrender.com`، و`onrender.com` مش ملكك — يعني معندكش صلاحية
تضيف أي سجل DNS عليه. الطريقة دي هتفضل تفشل مهما استنيت.

## الحل: «بادئة عنوان URL»

1. في Search Console اختار **URL prefix / بادئة عنوان URL** (الخانة الشمال،
   مش اليمين)
2. حط اللينك كامل:
   ```
   https://food-analyzer-duag.onrender.com
   ```
3. من طرق التحقق اختار **علامة HTML (HTML tag)**
4. هيديك سطر شكله كده — **انسخ المحتوى اللي جوه `content` بس**:
   ```html
   <meta name="google-site-verification" content="AbC123xyz..." />
   ```
5. في Render → الـ service → **Environment** → أضف:

   | Key | Value |
   |---|---|
   | `GOOGLE_SITE_VERIFICATION` | `AbC123xyz...` |

6. استنى الـ deploy يخلص (دقيقتين تلاتة)، وبعدين ارجع لجوجل ودوس **تحقّق**

## البديل: ملف HTML

لو فضّلت طريقة الملف، جوجل بيديك ملف اسمه `google<رمز>.html`. حط **اسم الملف**
في متغير البيئة:

| Key | Value |
|---|---|
| `GOOGLE_VERIFY_FILE` | `google1a2b3c4d.html` |

الموقع هيقدّم الملف على `/google1a2b3c4d.html` بالمحتوى اللي جوجل مستنيه. أي
اسم تاني بيرجع 404، فمفيش أي باب مفتوح هنا.

## بعد ما التحقق ينجح

1. **Sitemaps** → أضف `sitemap.xml` — فيه 541 لينك (الصفحات العامة + 522 صنف
   + 14 فئة)
2. **فحص عنوان URL** → اكتب لينك الموقع → **طلب الفهرسة**. كرّرها لـ `/foods`
3. استنى من يوم لتلاتة، وبعدين ابحث عن **NutraX** أو **نوتراكس**

الخطوة رقم 2 هي اللي بتفرق: بتنزّل وقت الفهرسة من أسابيع لساعات.

## لو ربطت دومين خاص بعدين

ساعتها الطريقتين هيشتغلوا، وطريقة الـ DNS هتنفع لأنك بقيت مالك النطاق فعلاً.
وقتها كمان حدّث `DOMAIN` في متغيرات البيئة عشان الـ canonical والـ sitemap
يتحركوا مع الدومين الجديد.

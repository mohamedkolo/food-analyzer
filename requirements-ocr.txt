# ‏قراءة ورقة التحليل من صورة، على السيرفر -- **مش محتاجة دلوقتي**.
#
# ‏القراءة بقت بتحصل في متصفح الدكتور نفسه (static/ocr + static/js/
# report_ocr.js)، فمافيش تركيب ولا مفتاح ولا إعداد استضافة. وأحسن كمان:
# صورة ورقة العميل مابتخرجش من الموبايل خالص.
#
# ‏الملف ده سايبينه لطريق تاني اختياري بس: القراءة على السيرفر بتشتغل
# برضه لو الحزمة متركّبة. ولو جرّبت -- الحزمة بتجرّ opencv-python العادية
# اللي محتاجة libGL.so.1، وده مش موجود على استضافة Render، فهتتركّب
# وتفضل مش شغالة. أمر البناء اللي بيصلّح ده:
#
#     pip install -r requirements.txt && (pip install -r requirements-ocr.txt \
#       && pip install --force-reinstall --no-deps opencv-python-headless || true)
#
# ليه في ملف لوحده: الحزمة دي بتجرّ وراها ~٢٠٠ ميجا (onnxruntime 67 +
# opencv 72 + numpy 45). ولما كانت في requirements.txt، فشل تركيبها كان
# بيفشّل **البناء كله** -- فالاستضافة بتسيب النسخة القديمة شغالة وكل
# التعديلات التانية بتفضل واقفة وراها. حصل فعلاً.
#
# للتفعيل: في إعدادات الاستضافة، خلّي أمر البناء:
#
#     pip install -r requirements.txt && (pip install -r requirements-ocr.txt || true)
#
# الـ|| true معناها: لو التركيب فشل، النشر يكمّل والموقع يشتغل من غير
# الميزة دي بس -- بدل ما ينهار كله.

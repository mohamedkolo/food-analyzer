# ‏الملف ده **فاضي بالقصد**، ومساب عشان أمر البناء اللي بيشاور عليه
# يفضل شغّال ومايعملش حاجة.
#
# ليه: قراءة ورقة التحليل بقت بتحصل في متصفح الدكتور نفسه
# (static/ocr + static/js/report_ocr.js). فمافيش مكتبة تتركّب على
# السيرفر، ولا مفتاح، ولا إعداد على الاستضافة -- والصورة كمان
# مابتخرجش من موبايله خالص.
#
# ‏وقبل كده كان فيه هنا rapidocr-onnxruntime، وهي:
#
#   ١. بتجرّ وراها ~٢٠٠ ميجا (onnxruntime ٦٧ + opencv ٧٢ + numpy ٤٥)،
#      فالبناء بيطوّل وممكن يفشل على الاستضافة المجانية.
#   ٢. محتاجة libGL.so.1 وده مش موجود على Render أصلاً -- يعني كانت
#      هتتركّب وتفضل مش شغالة.
#   ٣. النموذج بياخد ~٢٨٠ ميجا رام، والاستضافة عندها ٥١٢ والتطبيق
#      ماشي فيهم.
#
# ‏فلو أمر البناء عندك لسه مكتوب فيه:
#
#     pip install -r requirements.txt && (pip install -r requirements-ocr.txt || true)
#
# مافيش مشكلة -- السطر التاني مش بينزّل أي حاجة دلوقتي. ولو عايز
# تبسّطه، خليه: pip install -r requirements.txt
#
# ‏الكود اللي بيقرا على السيرفر (ocr_report.py) لسه موجود وعليه
# اختبارات، وبيشتغل لو حد ركّب الحزمة بإيده في بيئة فيها libGL.
